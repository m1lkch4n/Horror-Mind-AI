# Horror-Mind-AI

> **The horror isn't scripted. It thinks.**

**Horror-Mind-AI** is an open-source Minecraft mod that uses a local AI model as a dynamic horror director.

Instead of relying entirely on predefined scripts, Horror-Mind-AI allows an AI model to observe the game, analyze the player's actions and environment, and dynamically create events using a controlled set of Minecraft tools.

The goal is to create a horror experience that can remain unpredictable even after hundreds of playthroughs.

---

## Features

- **Local AI** — run supported AI models directly on the player's computer.
- **AI Horror Director** — the AI dynamically decides what should happen and when.
- **Tool Calling** — the AI can interact with the Minecraft world through controlled tools.
- **Generative Events** — combine actions, parameters, conditions, and randomness to create countless unique situations.
- **Context & Memory** — previous events and player behavior can influence future decisions.
- **Custom Prompts** — create your own AI personalities, behaviors, and horror scenarios.
- **Community Scenarios** — share and discover custom AI prompts and scenarios.
- **Open Source** — the engine, tools, and APIs are available for developers to extend.

---

## How It Works

Horror-Mind-AI acts as a bridge between Minecraft and a local AI model.

```
Minecraft
    |
    v
Game Events
    |
    v
World State
    |
    v
Local AI Model
    |
    v
Tool Calling
    |
    v
Minecraft Actions
    |
    v
New Events
    |
    +-------------------> AI
```

The AI receives relevant information about the current state of the game and can choose from a set of available tools.

For example, it may detect that a player has been alone in a cave for a long time and decide to:

- Create a strange structure in the distance.
- Play a sound behind the player.
- Modify nearby lighting.
- Spawn an entity.
- Make the entity disappear when approached.

The exact sequence can be generated dynamically rather than being manually scripted by the developer.

## Generative Horror

Horror-Mind-AI is designed around the idea that horror should not become predictable after repeated playthroughs.

AI behavior can depend on:

- the current world state;
- player actions;
- previous events;
- player behavior;
- the selected prompt;
- available tools;
- random parameters;
- contextual information.

This creates a large number of possible combinations without requiring developers to manually create every scenario.

## Custom AI Scenarios

Users can create custom prompts that define how the AI behaves.
These scenarios(prompts) can eventually be shared through a community platform built around Horror-Mind-AI.

## Community Ecosystem

A planned part of the project is the Horror-Mind-AI Hub — a platform for discovering and sharing AI scenarios.

Users could publish:

- custom prompts;
- AI personalities;
- horror scenarios;
- tool configurations;
- scenario collections;
- modified versions of existing scenarios.

The goal is to allow the community to continuously expand the range of experiences that can be generated by the engine.

## A Different Approach to Minecraft Horror

Traditional horror mods primarily rely on predefined events and scripts.

Horror-Mind-AI takes a different approach:

> **The developer creates the tools and rules. The AI creates the experience.**

The project aims to build an extensible AI-driven horror engine rather than a fixed collection of scripted scares.
